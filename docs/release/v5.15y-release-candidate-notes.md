# AgentLite v0.5.15rc2 Release Candidate Notes

## Changes since rc1

- installs the generated source distribution into an isolated target during
  the formal artifact gate;
- verifies import origin, project/runtime/distribution version identity,
  installed CLI behavior, and required runtime members;
- adds current competition installation and evidence guidance;
- adds source and issue URLs plus non-legal package classifiers.

The runtime semantic bridge, AutoGen takeover, state, memory, conflict,
reliability, and delivery behavior are unchanged from rc1.

## Verification

Run on a clean openEuler checkout:

```bash
bash experiments/v5.15y-installed-sdist-delivery-readiness/run_openeuler.sh
```

The generated acceptance report is authoritative. A candidate is technically
ready only when every inherited RC and installed-sdist check passes and all
artifact hashes are independently verified.

## Publication boundary

The repository still requires an explicit owner-selected license before public
open-source publication. RC2 does not infer or add one.
