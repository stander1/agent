# AgentLite v0.5.15rc2 发行候选说明

## 相对 rc1 的变化

- 在正式制品门禁中，将生成的源码发行包安装到隔离目标目录；
- 校验导入来源、项目/运行时/发行包版本一致性、已安装 CLI 行为和必需的
  运行时成员；
- 增加当前比赛安装与证据指南；
- 增加源码和问题反馈地址；
- 在仓库和包元数据中采用 Apache-2.0，并校验 wheel 与 sdist 中许可证
  内容的一致性。

运行时语义桥、AutoGen 接管、状态、记忆、冲突、可靠性和交付行为均与
rc1 保持一致。

## 验证

在干净的 openEuler 检出目录中运行：

```bash
bash experiments/v5.15y-installed-sdist-delivery-readiness/run_openeuler.sh
```

生成的验收报告是判定依据。仅当所有继承自 RC 的检查和已安装 sdist 检查
均通过，并且全部制品哈希得到独立验证时，候选版本才达到技术就绪状态。

## 公开发布就绪条件

项目所有者已选择 Apache-2.0。只有最终 openEuler 报告确认 SPDX 表达式、
许可证文件、wheel 与 sdist 中的许可证内容、制品哈希以及所有继承的技术
检查均通过时，项目才达到公开开源发布条件。
