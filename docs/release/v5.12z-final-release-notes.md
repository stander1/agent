# AgentLite v5.12z 最终发行说明

## 发行范围

`v5.12z` 是 AgentLite AutoGen Python 代码集成路径的首个包级发行候选版本。

该版本证明：

- 项目能够构建为 wheel 和 sdist 制品；
- wheel 能够在源码目录之外安装；
- `agentlite run --framework autogen --rewrite all -- python app.py` 能够在
  用户导入前透明修补 AutoGen Python 代码；
- AutoGen Team 入口文本能够替换为包含 StatePool 引用、广播清单和接收方
  Prompt View 的 AgentLite SHP-State 数据包。

该版本不宣称：

- 已发布到 PyPI；
- 已发布为 GitHub Release；
- 已集成 AutoGen Studio 或 Web UI；
- 已覆盖所有 AutoGen 私有消息路径或所有任务类型；
- 已达到长期、多操作系统生产兼容性。
