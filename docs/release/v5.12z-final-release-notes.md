# AgentLite v5.12z Final Release Notes

## Release Scope

`v5.12z` is the first package-level release candidate for the AgentLite AutoGen Python-code integration path.

It proves:

- The package can be built into wheel and sdist artifacts.
- The wheel can be installed outside the source tree.
- `agentlite run --framework autogen --rewrite all -- python app.py` can transparently patch AutoGen Python code before user imports.
- AutoGen Team entry text can be replaced by an AgentLite SHP-State packet with StatePool refs, broadcast manifest, and receiver Prompt Views.

It does not claim:

- PyPI publication.
- GitHub Release publication.
- AutoGen Studio / web UI integration.
- Coverage of every AutoGen private message path or every task type.
- Long-running multi-OS production compatibility.
