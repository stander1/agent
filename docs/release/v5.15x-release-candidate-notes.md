# AgentLite v0.5.15rc1 Release Candidate Notes

## Scope

This release candidate freezes the current AgentLite competition delivery
implementation after:

- the generic semantic bridge passed a post-commit, previously unseen domain
  holdout;
- the independently installed wheel passed AutoGen Team and mixed Team/Core
  takeover checks on openEuler;
- the complete source release gate and full unit suite passed;
- source, runtime, wheel, and sdist version identities were aligned.

The release candidate includes:

- cross-framework runtime, StatePool, Prompt View, and AutoGen takeover paths;
- fact-level claim extraction, schema validation, conflict resolution, memory
  admission, and typed reliability events;
- controlled semantic disambiguation with strict source-span validation,
  bounded Provider cost, and failure-closed admission;
- explicit cost protection that rewrites only when the candidate path reduces
  cost, otherwise preserving the native message without mutation;
- CLI, monitor, examples, tests, planning records, and reproducible openEuler
  acceptance experiments.

## Evidence limits

Passing the fixed A/B suites does not prove universal cross-domain semantics.
The post-commit holdout proves one additional unseen domain and the generic
mechanism invariants measured by that gate. Provider cost and quality claims
remain bounded to their archived scenarios, models, prompts, and thresholds.

The release candidate does not claim support for every AutoGen private API or
every multi-agent framework.

## Publication status

The technical release candidate can be built and verified without Provider
credentials. Public open-source publication remains blocked until the project
owner chooses and adds an explicit repository license.

## Verification

Run on a clean openEuler checkout:

```bash
bash experiments/v5.15x-release-candidate-freeze/run_openeuler.sh
```

The gate produces:

- an independently installed wheel report;
- a complete source release report;
- wheel and sdist artifacts with SHA256;
- an acceptance report and immutable evidence archive.
