# AgentLite v0.5.15rc1 发行候选说明

## 范围

该发行候选版本冻结了当时的 AgentLite 比赛交付实现，冻结前已完成：

- 通用语义桥通过提交后的、开发期间不可见的新领域 holdout 验收；
- 独立安装的 wheel 在 openEuler 上通过 AutoGen Team 和 Team/Core
  混合接管检查；
- 完整源码发行门禁和全部单元测试通过；
- 源码、运行时、wheel 和 sdist 的版本标识完成统一。

该发行候选版本包含：

- 跨框架运行时、StatePool、Prompt View 和 AutoGen 接管路径；
- 事实级 claim 提取、Schema 校验、冲突消解、记忆准入和类型化可靠性事件；
- 带严格 source span 校验、受限 Provider 成本和失败关闭准入的受控语义消歧；
- 显式成本保护：仅在候选路径降低成本时执行改写，否则原样保留原生消息；
- CLI、监控器、示例、测试、规划记录及可复现的 openEuler 验收实验。

## 证据边界

固定 A/B 测试集通过并不证明对所有领域都具备通用语义能力。提交后的
holdout 仅证明一个额外不可见领域，以及该门禁所测量的通用机制不变量。
Provider 成本和质量结论仅适用于归档中记录的场景、模型、提示词和阈值。

该发行候选版本不宣称支持所有 AutoGen 私有 API，也不宣称支持所有
多智能体框架。

## 发布状态

该技术候选版本无需 Provider 凭据即可构建和验证。由于当时项目所有者尚未
选择并添加明确的仓库许可证，公开开源发布仍处于阻塞状态。

## 验证

在干净的 openEuler 检出目录中运行：

```bash
bash experiments/v5.15x-release-candidate-freeze/run_openeuler.sh
```

该门禁会生成：

- 独立安装的 wheel 验证报告；
- 完整源码发行报告；
- 带 SHA256 的 wheel 和 sdist 制品；
- 验收报告与不可变证据归档。
