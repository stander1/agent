# AgentLite v0.5.15 最终发行说明

## 发行定位

AgentLite `0.5.15` 是面向本次比赛交付的最终版本。该版本将已经验证的
RC2 运行时提升为正式版，不改变通用语义桥、AutoGen 接管、StatePool、
记忆、冲突处理、可靠性、成本统计或交付行为。

## 定版变更

- 将软件包和运行时版本统一为非预发行版本 `0.5.15`；
- 将项目所有者选定的 Apache-2.0 许可证纳入仓库、wheel、sdist 和
  Core Metadata；
- 要求完成隔离的 wheel 与 sdist 安装、CLI 与导入来源检查、完整
  openEuler 单元测试、制品内容检查和独立 SHA256 校验；
- 增加最终比赛安装与证据指南；
- 保留现有 `v0.5.15rc2` 标签，作为不可变的历史证据。

## 验证

在干净的 openEuler 检出目录中运行：

```bash
bash experiments/v5.15y-installed-sdist-delivery-readiness/run_openeuler.sh
```

仅当所有验收检查均通过、`open_source_publication_ready=true`、发布阻塞项
为空，并且取回的证据及发行制品与记录的 SHA256 一致时，该版本才可发布。
