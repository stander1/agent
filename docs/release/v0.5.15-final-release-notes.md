# AgentLite v0.5.15 Final Release Notes

## Release

AgentLite `0.5.15` is the final competition delivery release. It promotes the
verified RC2 runtime without changing semantic bridge, AutoGen takeover,
StatePool, memory, conflict, reliability, cost-accounting, or delivery
behavior.

## Finalization changes

- adopts the final non-prerelease package and runtime version `0.5.15`;
- carries the owner-selected Apache-2.0 license in the repository, wheel,
  sdist, and Core Metadata;
- requires isolated wheel and sdist installation, CLI and import-origin checks,
  full openEuler unit tests, artifact content checks, and independent SHA256
  verification;
- adds the final competition installation and evidence guide;
- preserves the existing `v0.5.15rc2` tag as immutable historical evidence.

## Verification

Run on a clean openEuler checkout:

```bash
bash experiments/v5.15y-installed-sdist-delivery-readiness/run_openeuler.sh
```

The release is publishable only when every acceptance check passes,
`open_source_publication_ready=true`, publication blockers are empty, and the
retrieved evidence and release artifacts match their recorded SHA256 values.
