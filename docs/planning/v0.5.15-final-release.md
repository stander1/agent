# v0.5.15 Final Competition Release

## Scope

The final release promotes the verified RC2 runtime and the owner-selected
Apache-2.0 license to package version `0.5.15`. No production runtime,
benchmark, role, task, domain parser, memory policy, or semantic rule changes
are included.

## Immutable version boundary

The published `v0.5.15rc2` tag is historical and must not be moved. The final
`v0.5.15` tag may be created only after the exact source commit passes the
complete openEuler no-Provider release gate and its evidence archive is
retrieved and independently verified.

## Final gate

The final report must establish:

- project, runtime, wheel, sdist, installed distribution, and CLI version
  identity at `0.5.15`;
- independent wheel and sdist installation outside the source checkout;
- full unit-suite and focused release-contract success;
- required package members and absence of forbidden evidence paths;
- Apache-2.0 identity and content consistency across source and artifacts;
- independently recomputed artifact and evidence SHA256 values;
- zero open-source publication blockers.

Provider-backed A/B experiments are not repeated because this promotion changes
release metadata and documentation only. Any gate failure blocks tagging and
must be resolved at the release-contract level before publication.
