# v0.5.15 最终比赛发行版

## 范围

最终发行版将已验证的 RC2 运行时和项目所有者选定的 Apache-2.0 许可证
提升到软件包版本 `0.5.15`。本阶段不包含生产运行时、基准、角色、任务、
领域解析器、记忆策略或语义规则变更。

## 不可变版本边界

已经发布的 `v0.5.15rc2` 标签属于历史记录，不得移动。只有精确源码提交
通过完整的 openEuler 无 Provider 发行门禁，且证据归档已取回并完成独立
校验后，才可创建最终 `v0.5.15` 标签。

## 最终门禁

最终报告必须证明：

- 项目、运行时、wheel、sdist、已安装发行包和 CLI 的版本均为 `0.5.15`；
- wheel 和 sdist 均在源码检出目录之外完成独立安装；
- 完整单元测试集和聚焦的发行契约测试通过；
- 必需的软件包成员齐全，且不包含禁止进入制品的证据路径；
- 源码与制品中的 Apache-2.0 标识和内容一致；
- 制品和证据归档的 SHA256 均已独立重算；
- 开源发布阻塞项为零。

由于本次提升仅改变发行元数据和文档，因此不重复运行依赖 Provider 的 A/B
实验。任何门禁失败都会阻止创建标签，并且必须先在发行契约层解决后才能发布。
