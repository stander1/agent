# v5.15r Structured Dependency Cost Override

## Frozen v5.15q failure

The immutable v5.15q archive `20260729-104416` passed 22 of 25 checks. Typed
state admission, supersession binding, historical field fetch, role-view
retention, protocol hygiene, and zero transport retries were correct. The final
delivery nevertheless failed for all configured receivers.

The direct trace chain was:

1. the final team task retrieved two MemoryRefs and expanded the requested
   historical predecessor;
2. its control semantic-dependency call ended in `provider_error` with no
   transport retry;
3. the runtime therefore marked continuity as not required;
4. each receiver generated a complete typed rewrite candidate, but rejected it
   with `token_not_reduced`;
5. the native transcript had been intentionally cleared, so the model could not
   resolve the requested values.

The archive remains failed. Its evidence is used to define this repair rather
than being rewritten or reclassified.

## Generic mechanism

The runtime now separates deterministic protocol semantics from genuinely
ambiguous semantic control:

- `requests_historical_state` recognizes explicit current/history intent using
  the shared temporal intent layer;
- that intent emits `explicit_historical_state_request` with zero Provider
  calls, tokens, and retries;
- the task-sequence-bound reason is inherited by all receivers;
- the existing continuity cost exception applies only when memory was retained
  and every fallback reason is a cost-only reason;
- ambiguous dependencies still use the controlled LLM analyzer and retain their
  existing accounting path.

A model-response boundary is prepended to applied evidence views. It asks the
model to answer the task directly and treats serialized records as evidence,
not an output schema. The audit event records parsed protocol facts only when
the rewrite was actually applied, and binds dependency decisions to the same
task sequence as receiver rewrites.

## Evidence gate

The v5.15r verifier extends v5.15q and requires:

- one structured final-task dependency event with zero calls, tokens, and
  retries;
- an applied, structured-continuity rewrite for every configured receiver;
- explicit continuity cost override for every final rewrite whose token count
  is not lower than native input;
- no final cost-guard passthrough;
- an applied response boundary and complete typed facts for every receiver;
- the inherited typed revision, predecessor binding, output quality, Provider,
  control, transport, field-fetch, retry, and protocol checks.

External scenario and team files must be authored after the implementation and
verifier commit. Production code and tests contain no holdout domain names,
values, units, predicates, or fixed role names.

## Boundary

This repair does not bypass structural rewrite guards, force arbitrary memory
into prompts, or grant all larger rewrites a cost exception. It applies only to
an explicit structured historical-state request with retained evidence. A pass
proves the preregistered mechanism on one unseen chain, not universal semantic
coverage.
