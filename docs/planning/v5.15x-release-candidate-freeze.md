# v5.15x Release Candidate Freeze

## Goal

v5.15x converts the verified `0.5.15.dev0` checkout into a reproducible
`0.5.15rc1` competition release candidate. It does not change runtime
semantics. It closes the remaining artifact-contract drift between the
installed wheel gate and the wheel/sdist builder.

## Shared artifact contract

`examples/release_package_contract.py` is the single source of truth for:

- required runtime and semantic bridge wheel members;
- reproducibility files required in the source distribution;
- paths that must never enter wheel or sdist artifacts.

Both `run_package_release_gate.py` and `build_release_artifacts.py` consume the
same contract. The builder also verifies that `pyproject.toml` and
`agent_runtime.__version__` agree.

## Acceptance boundary

The openEuler acceptance runs:

1. release-contract unit tests;
2. independent wheel installation and AutoGen takeover smokes;
3. the complete source release gate and unit suite;
4. wheel and sdist construction plus independent hash verification;
5. immutable evidence packaging and SHA256 validation.

Technical RC success does not silently choose a legal license. The acceptance
records an explicit publication blocker while no repository license exists.
