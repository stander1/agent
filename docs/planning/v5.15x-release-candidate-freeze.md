# v5.15x 发行候选冻结

## 目标

v5.15x 将已验证的 `0.5.15.dev0` 检出版本转换为可复现的 `0.5.15rc1`
比赛发行候选版本。该阶段不改变运行时语义，只消除已安装 wheel 门禁与
wheel/sdist 构建器之间残留的制品契约漂移。

## 统一制品契约

`examples/release_package_contract.py` 是以下规则的唯一事实来源：

- wheel 必须包含的运行时和语义桥成员；
- 源码发行包必须包含的复现文件；
- 任何情况下都不得进入 wheel 或 sdist 的路径。

`run_package_release_gate.py` 和 `build_release_artifacts.py` 共同使用该
契约。构建器还会校验 `pyproject.toml` 与 `agent_runtime.__version__`
是否一致。

## 验收边界

openEuler 验收执行：

1. 发行契约单元测试；
2. 独立 wheel 安装与 AutoGen 接管冒烟测试；
3. 完整源码发行门禁与全部单元测试；
4. wheel 和 sdist 构建及独立哈希校验；
5. 不可变证据打包与 SHA256 校验。

技术 RC 通过不代表可以替项目所有者选择法律许可证。在当时仓库尚无许可证
时，验收报告会明确记录公开发布阻塞项。
