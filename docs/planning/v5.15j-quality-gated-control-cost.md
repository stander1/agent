# v5.15j Quality-Gated Control Cost

## Evidence

The v5.15i post-commit holdout passed every semantic and protocol gate, but
used 12 control-model calls and 10,398 control Provider tokens.

Nine calls were made for intermediate or unvalidated outputs whose fixed
quality envelope guaranteed a pending, rejected, or audit-only result even
when semantic parsing succeeded. Those calls consumed 7,077 tokens and could
not create reusable memory.

## Mechanism

MemoryStore now exposes one domain-independent quality-envelope classifier.
The admission path and the AutoGen control-call gate use the same thresholds,
so policy cannot drift between cost control and memory admission.

- `control_required` remains mandatory for direct source evidence.
- `fallback` remains available for candidates that can become admitted.
- `rules_only` keeps low-authority candidates and deterministic claims in the
  normal audit path without spending control-model tokens.

The decision depends only on confidence, importance, coverage, compression
risk, and raw-evidence requirements. It does not inspect task vocabulary,
domain names, values, units, or agent roles.

## Expected Effect

For the observed three-task chain, semantic disambiguation calls associated
with seven intermediate outputs and two unvalidated team outputs become
rules-only. Direct-source and discourse-dependency calls remain fully
metered and unchanged.
