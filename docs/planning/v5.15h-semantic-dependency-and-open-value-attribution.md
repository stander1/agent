# v5.15h Semantic Dependency and Open-Value Attribution

## Evidence

The post-commit integrated holdout at `cfb9c3a` admitted direct framework
source evidence and retrieved it consistently, but only applied the memory
view when a fixed lexical continuity cue matched. A new expression of
cross-task dependence therefore passed retrieval but failed the cost override.

The same run also showed a canonical open-schema value copied into downstream
output while adoption telemetry remained unassessed. The attribution path
depended on the compatibility claim extractor recognizing the output domain.

## General Mechanism

AgentLite now uses a bounded semantic dependency classifier only when:

1. the current collaboration group has admitted memory hits;
2. deterministic continuity cues did not already establish necessity; and
3. the task is later than the first task in the group.

The classifier cannot create or approve facts. It returns only:

- whether prior context is required;
- selected IDs from the retrieved memory set;
- an exact, unique quote from the current task that expresses the dependency;
- confidence.

Unknown memory IDs, invented or repeated quotes, malformed schemas, low
confidence, provider errors, and budget exhaustion all fail closed. A positive
team-level decision is cached by collaboration group and task sequence, then
reused by arbitrary team participants. This avoids fixed agent roles and
duplicate classifier calls.

For adoption telemetry, an open CanonicalClaim value can now be matched
literally when the compatibility extractor cannot recognize its domain. The
match still excludes values already present in the current task, respects
numeric boundaries and units, and retains active-versus-historical checks.

## Non-Goals

- No Question A/B identifiers or task-specific values are present.
- No domain vocabulary was added.
- No global admission threshold was lowered.
- A semantic dependency decision does not grant memory authority.
- Marker-free team output remains ineligible for final-output admission.

## Required Acceptance

The next external holdout must demonstrate:

- semantic dependency classification with an implementation-time unseen
  expression;
- cost override only for selected admitted memory;
- downstream output that uses the retrieved open-schema value;
- nonzero memory-supported output telemetry;
- complete accounting of team, control, transport, retry, and provider tokens.
