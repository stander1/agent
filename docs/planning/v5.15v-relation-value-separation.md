# v5.15v Relation-Value Separation

## Failure evidence

The post-commit v5.15u holdout preserved decoded model content and completed
with zero Provider retries, but passed only 28 of 39 checks. A controlled
semantic proposal emitted a typed revised value and a second same-predicate
candidate whose string value was the relation clause itself. Conflict
compaction then preferred that relation-bearing string as the active value.

A separate attribution gap was also observed: a model-produced one-line list
of multiple key-value assignments was parsed as one coarse candidate, so
memory use fell back to scalar literal matching instead of exact open
predicate matching.

## General repair

The repair uses no scenario, role, unit, or domain vocabulary.

- Multiple assignments on one line are split only at top-level separators
  followed by another assignment. Quotes and balanced brackets protect
  embedded separators, and every emitted candidate keeps an exact source
  span.
- A relation carrier may be locally coalesced only when it is adjacent to the
  same open predicate, the receiving value is already typed as non-string,
  the carrier is a string whose evidence is exactly that string, and its
  relation target is structurally embedded in the carrier value.
- Coalescing creates one union evidence span, merges relation metadata, and
  records `locally_coalesced_relation_candidate_count`.
- String-to-string revisions remain separate and are never coalesced by this
  rule.
- Relation attachment is bounded to a local 64-character evidence gap.

## Acceptance boundary

The v5.15v gate inherits v5.15u and additionally requires zero active claims
whose string value is structurally indistinguishable from their own relation
carrier. Unit tests cover inline typed assignments, quoted commas, grouped
numbers, exact open attribution, typed revision closure, and conservative
string revision behavior.

A post-commit external holdout must still demonstrate exact open attribution,
bound active/historical revision identity, decoded model-content attribution,
zero legacy-domain candidates, zero retries, and complete delivery. Passing
the holdout is evidence for its unseen scenarios, not a universal proof.
