# v5.15y 已安装 sdist 与交付就绪

## 证据驱动范围

不可变的 v0.5.15rc1 门禁已通过 wheel 安装、完整源码发行检查、全部单元测试、
wheel/sdist 内容检查和制品哈希校验。后续审计发现两个发行表面缺口：

1. 正式门禁检查了 sdist，但未实际安装；
2. 当时的比赛交付指南仍描述较早的、尚未集成 AutoGen 和 openEuler 的实现。

## 通用修复

制品构建器现在会在不安装依赖、不启用构建隔离的条件下，将生成的 sdist
安装到隔离目标目录。在检出目录之外运行的探针会：

- 从目标目录导入 `agent_runtime`；
- 比较运行时、发行包和项目版本；
- 调用已安装的 `agentlite version` 入口；
- 校验已安装目录中的所有 wheel 契约必需成员。

这是发行包层的契约，不包含任务标识、固定角色名称、领域词表、数值模式或
语义准入逻辑。

## 交付表面

当前交付指南记录安装、验证、证据边界、凭据处理和项目所有者选定的
Apache-2.0 许可证。软件包元数据使用 Apache-2.0 SPDX 表达式并包含
`LICENSE`。制品门禁会校验 wheel 和 sdist 中的许可证内容与仓库源码一致。

## 验收

最终 openEuler 门禁必须通过继承的 RC 检查、明确的已安装 sdist 检查、
Apache-2.0 元数据与制品内容检查，并清除所有发布阻塞项。
