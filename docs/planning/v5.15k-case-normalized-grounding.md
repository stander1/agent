# v5.15k Case-Normalized Grounding

## Evidence

The post-v5.15j diffraction holdout preserved every preregistered value and
status in its complete Agent outputs. The acceptance verifier nevertheless
reported one missing fragment because the scenario used `superseded` while
the generated heading used `Superseded`.

This was an evaluation false negative. It was not a memory retrieval,
injection, attribution, or delivery failure.

## Mechanism

The integrated holdout verifier now compares required and forbidden natural
language fragments with Unicode-aware `casefold()`. Numeric values, units, and
all other characters remain exact substring requirements.

The normalization is symmetric:

- required evidence is not rejected solely because of capitalization;
- forbidden evidence cannot evade detection through capitalization.

No production runtime path, domain vocabulary, task value, or Agent role is
changed.

## Evidence Boundary

The failed run remains immutable and is retained as evidence of the verifier
defect. A new holdout authored after this commit is required before the gate
can pass; the old output is not rescored in place as formal acceptance.
