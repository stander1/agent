# v5.12d-prep：真实 AutoGen 原生样例验证准备

## 1. 版本目标

`v5.12d` 的目标不是继续用伪 AutoGen 包，而是安装真实 `autogen-agentchat` / `autogen-core` 后，验证普通 AutoGen Python 程序在托管启动下能被 AgentLite 透明接入。

本准备版本先落地样例和校验脚本，不安装依赖、不宣称真实验证完成。

## 2. 固定依赖版本

PyPI 当前元数据显示：

```text
autogen-agentchat: 0.7.5
autogen-core: 0.7.5
autogen-ext: 0.7.5
```

本仓库的 `pyproject.toml` 新增：

```toml
[project.optional-dependencies]
autogen = [
  "autogen-agentchat==0.7.5",
  "autogen-core==0.7.5",
]
```

比赛版先使用无 API key 的 `UserProxyAgent` + `RoundRobinGroupChat` smoke，避免把验证结果和外部模型服务波动混在一起。

## 3. 新增样例

```text
examples/autogen_native_roundrobin_smoke.py
```

该脚本只导入 AutoGen：

```text
autogen_agentchat.agents.UserProxyAgent
autogen_agentchat.teams.RoundRobinGroupChat
autogen_agentchat.conditions.TextMentionTermination
autogen_agentchat.messages.TextMessage
autogen_core.CancellationToken
```

它不导入 AgentLite，也不调用本项目 SDK。

## 4. 新增校验脚本

```text
examples/run_autogen_native_smoke.py
```

该脚本负责：

```text
1. 检查 autogen_agentchat / autogen_core 是否安装；
2. 使用 ManagedProcessLauncher 以 framework=autogen 启动原生样例；
3. 读取 bootstrap_status.json；
4. 读取 autogen_driver/trace.jsonl；
5. 检查 autogen_agent_receive / autogen_agent_output；
6. 检查 state_ref 是否写入；
7. 输出 JSON 和 Markdown 报告。
```

## 5. 安装后命令

安装依赖：

```powershell
python -m pip install -e ".[autogen]"
```

运行 smoke：

```powershell
python .\examples\run_autogen_native_smoke.py
```

当前 shell 若没有刷新 `agentlite` console script 也没有关系，校验脚本直接调用 `ManagedProcessLauncher`。

## 6. 验收标准

`v5.12d` 正式完成必须满足：

```text
target_returncode_zero=true
bootstrap_ok=true
hooks_active=true
driver_phase_v5_12c=true
app_output_written=true
agentlite_active_in_target=true
receive_event_recorded=true
output_event_recorded=true
state_ref_recorded=true
```

注意：通过这些标准后，仍只能说明真实 AutoGen Python 代码端最小样例已透明接入；AutoGen Studio 网页端托管仍属于 v5.13。
