# v5.12u AutoGen Integrated Rewrite Results

## 结论

本实验验证：用户脚本只导入 AutoGen，不显式导入 AgentLite；通过

```powershell
agentlite run --framework autogen -- python app.py
```

这一类托管启动方式后，AgentLite 可以在底层接管 AutoGen agent 输入，并对 `TextMessage`、`HandoffMessage`、`ToolCallSummaryMessage` 三类消息完成真实替换。

这里的“真实替换”不是只记录 shadow trace，而是 AutoGen agent 实际读到的 `content` 已经变成 SHP wire + Prompt View；同时非文本消息的关键原生字段仍由 AutoGen 对象保留。

## 用户脚本约束

综合脚本 `examples/autogen_integrated_rewrite_smoke.py` 只导入 AutoGen 相关类：

```text
BaseChatAgent
Response
TextMessage
HandoffMessage
ToolCallSummaryMessage
CancellationToken
FunctionCall
FunctionExecutionResult
```

它不导入 `agent_runtime`，也不调用 AgentLite API。AgentLite 只通过托管启动注入底层 patch。

## 开关配置

```text
AGENTLITE_AUTOGEN_BROADCAST_MODE=real-rewrite
AGENTLITE_AUTOGEN_HANDOFF_REWRITE=1
AGENTLITE_AUTOGEN_TOOL_SUMMARY_REWRITE=1
```

含义：

- `real-rewrite`：真实替换 agent 输入层消息内容。
- `HANDOFF_REWRITE=1`：允许 HandoffMessage 在安全条件通过后替换 `content`。
- `TOOL_SUMMARY_REWRITE=1`：允许 ToolCallSummaryMessage 在安全条件通过后替换 `content`。

## 总体指标

```text
event_count: 3
applied_count: 3
fallback_count: 0
real_message_mutation_count: 3
native_input_tokens: 3930
rewritten_input_tokens: 942
token_delta_native_minus_rewrite: 2988
```

中文解释：

- `event_count`：本次 agent 输入改写事件数量。
- `applied_count`：真实替换成功次数。
- `fallback_count`：安全回退次数，本次为 0，说明三条 happy path 都通过安全条件。
- `real_message_mutation_count`：原生消息对象内容被真实改动的次数。
- `token_delta_native_minus_rewrite`：原生输入 token 减去替换后输入 token，本次节省 2988 token。

## 三类消息结果

| case | AutoGen 消息类型 | rewrite_marker_kind | native_marker_count | StatePool 标记 | Prompt View | 关键原生字段 |
|---|---|---|---:|---:|---:|---|
| text_message_real_rewrite | TextMessage | text | 0 | true | true | source 保留 |
| handoff_message_real_rewrite | HandoffMessage | handoff | 0 | true | true | source/target/id/metadata/context 保留 |
| tool_summary_message_real_rewrite | ToolCallSummaryMessage | tool_summary | 0 | true | true | id/source/metadata/tool_calls/results 保留 |

ToolCallSummary 链路保留：

```text
tool_call_ids: ['call_integrated_tool_1']
tool_result_call_ids: ['call_integrated_tool_1']
tool_result_error_flags: ['call_integrated_tool_1:False']
```
