# v5.12s AutoGen ToolCallSummary Typed Rewrite Candidate 实验记录

## 版本定位

`v5.12s` 是 ToolCallSummaryMessage 真实改写前的 typed rewrite candidate 版本。

typed rewrite candidate：类型化改写候选。这里的意思是系统先生成一份“如果将来要改写，应如何把长正文迁移到 StatePool，并用 SHP wire + Prompt View 交付”的候选包，同时验证原生 AutoGen 消息里的关键控制字段是否能完整保留。本版本不真实改写 ToolCallSummaryMessage。

lineage：链路 / 血缘关系。这里主要指工具调用请求与工具执行结果之间的对应关系，例如 `tool_calls.id` 必须和 `results.call_id` 对得上。

## 新增内容

- AutoGen Driver phase 更新为 `v5.12s`。
- 非文本真实改写分支新增 ToolCallSummary typed candidate 生成逻辑。
- 新增候选合约：`autogen_tool_summary_typed_rewrite_candidate.v1`。
- 新增 candidate 内容标记：`AGENTLITE_TOOL_SUMMARY_TYPED_REWRITE_CANDIDATE v1`。
- 新增 `examples/autogen_tool_summary_candidate_smoke.py`。
- 新增 `examples/run_autogen_tool_summary_candidate_smoke.py`。
- 扩展 typed candidate 汇总字段：
  - `tool_call_ids`
  - `tool_call_names`
  - `tool_result_call_ids`
  - `tool_result_names`
  - `tool_result_error_flags`

## 下一步建议

下一步应进入 ToolCallSummary rewrite matrix。建议覆盖：

```text
1. 正常 call_id 对齐时 candidate_safe=true；
2. results.call_id 缺失或不匹配时 candidate_safe=false；
3. 多工具调用、多结果时 lineage 必须完整；
4. 短 ToolCallSummary 不降 token 时必须回退；
5. is_error=true 的工具结果必须保留错误状态；
6. 仍然不真实 mutation，直到矩阵稳定。
```
