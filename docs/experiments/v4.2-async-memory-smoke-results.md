# v4.2 异步记忆准入 smoke 结果

日期：2026-06-21

## 目标

v4.2 验证主执行链路与后台治理链路拆分：

- 主执行链路：LLM 输出、Contract Guard、状态池写入、SHP 传递。
- 后台治理链路：记忆候选池判断、MemoryView 更新、记忆写入指标。

下一个任务开始检索记忆前，运行时会 flush 上一轮后台记忆任务，保证连续任务仍能读到已沉淀记忆。

## 实现要点

- `writer/reviewer/memory_manager` 输出后不再同步等待记忆准入。
- 运行时调度 `background_memory_scheduled` 后，下游 Agent 可继续执行。
- `before_memory_search` 和 `benchmark_finished` 会收束后台任务。
- 新增指标：
  - `background_memory_job_count`
  - `background_memory_completed_count`
  - `background_memory_error_count`
  - `background_memory_wait_ms`

## 结论

v4.2 没有改变记忆准入规则，只改变等待方式。smoke 结果显示后台记忆准入可以从主 Agent 链路中拆出，且没有破坏格式稳定性、记忆写入或连续任务读取。

完整 A/B 压测可在后续作为 v4.2 正式实验运行，用于衡量 runtime_lite 相对 v4.1 的端到端耗时变化。
