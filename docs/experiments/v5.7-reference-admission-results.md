# v5.7 Memory Reference / State Admission Lite 记录

日期：2026-06-22

## 1. 本轮目标

继续根据外部审计与二次复核文档补齐非 AutoGen 缺口：

1. `Memory Reference Manager` 未实现。
2. `State Admission Control` 未实现。
3. 记忆引用缺少 strong / weak / lineage / evidence 四类关系。
4. 记忆替换缺少 tombstone + replacement chain。
5. 状态池写入缺少评分公式，容易被质疑“什么都进状态池”。

英文术语说明：

1. `Memory Reference Manager`：记忆引用管理器，记录一条记忆依赖哪些 claim、view、state、evidence。
2. `strong reference`：强引用，记忆成立所必须的核心对象，例如 claim 和 MemoryView。
3. `weak reference`：弱引用，辅助追踪对象，例如 PromotionView。
4. `lineage reference`：血缘引用，记录记忆来自哪些 State。
5. `evidence reference`：证据引用，记录支撑记忆的证据来源。
6. `State Admission Control`：状态准入控制，用评分决定一个状态是否值得作为可复用状态进入池中。

## 3. MemoryStore 接入

`MemoryStoreLite` 新增：

```text
self.reference_manager
memory_references()
replace_memory()
_create_memory_references()
```

写入记忆时自动创建：

1. strong：memory -> claim。
2. strong：memory -> memory_view。
3. weak：memory -> promotion_view。
4. lineage：memory -> source_state_ids。
5. evidence：memory -> evidence_refs。

当记忆进入 blocked 状态，例如：

```text
deprecated
deleted
superseded
unresolved_conflict
pending_lifecycle_update
```

相关引用会 tombstone。

显式调用 `replace_memory(old_ref, new_ref)` 时，会登记 replacement chain：

```text
old_memory_id -> new_memory_id
```

## 4. State Admission Control Lite

`StatePoolLite` 新增：

```text
StateAdmissionPolicy
StateAdmissionReport
StatePoolLite.assess_state_admission()
```

准入公式：

```text
score =
  downstream_need_weight * downstream_need
+ confidence_weight * confidence
+ novelty_weight * novelty
- size_penalty_weight * size_penalty
```

默认权重：

```text
downstream_need_weight = 0.45
confidence_weight = 0.35
novelty_weight = 0.20
size_penalty_weight = 0.15
admit_threshold = 0.45
```

每个 `StateObject` 现在记录：

```text
admission_score
admission_status
```

当前比赛版不会因为低分直接让流程崩溃，而是标记为：

```text
audit_only
```

这样既有准入控制证据，又不破坏现有实验链路。

## 6. 已解决与未解决

已解决：

1. Memory Reference Manager Lite 落地。
2. strong / weak / lineage / evidence 四类引用落地。
3. tombstone + replacement chain 落地。
4. State Admission Control Lite 落地。
5. 状态对象记录 admission_score / admission_status。

仍未解决：

1. Memory Reference Manager 仍是内存版，没有 SQLite / openGauss 持久化。
2. replacement chain 目前由显式 `replace_memory()` 触发；自动冲突替换只会 tombstone 旧引用。
3. State Admission 当前是规则公式，没有 LLM / embedding 参与评分。
4. 低分状态当前不会被硬拒绝，只标记为 audit_only，比赛版更稳，研究版可进一步严格化。
