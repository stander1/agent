# v5.14v Continuity and Memory Formal Regression

v5.14v returns the v5.14u mechanism to the unchanged real MiMo Provider
experiment. It reuses the exact v5.14t A1-A10/B1-B10 tasks, capability-based
Agent configurations, model, temperature, turn limit, anonymous judges, cost
accounting, and all existing thresholds.

## Added evidence

The post-verifier reads the Managed AgentLite traces copied into each scenario's
run evidence and records:

- `autogen_memory_candidate` events where a compact approval resolved to a
  preceding validated artifact and produced typed memory references;
- `autogen_current_task_identity_guard` events, including task sequence,
  unsupported label assertions, and unsupported interaction ordinals.

The experiment requires at least one non-rejected approved-artifact memory
resolution. It does not require a minimum number of identity blocks because the
model may produce no identity drift; any observed block must nevertheless be
well-formed and sequence-grounded.

## Fairness boundary

Production runtime code does not identify Question A/B, business entities,
fixed conclusions, or fixed Agent names. No task, prompt, output length, turn
limit, scoring rule, or existing cost/quality threshold is relaxed.
