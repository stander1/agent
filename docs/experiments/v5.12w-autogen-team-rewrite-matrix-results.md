# v5.12w AutoGen Team Rewrite Matrix Results

## 结论

`v5.12w` 为 `v5.12v` 的 AutoGen Team 入口层真实改写增加边界矩阵。

矩阵证明：

```text
长 task: str 可以真实改写；
开关关闭时必须保留原生任务；
短 task 因成本门控不划算而安全回退；
TextMessage task 和 list task 因类型暂不支持而安全回退；
task=None 因缺少任务参数而安全回退；
RoundRobinGroupChat.run(...) 间接调用 run_stream 时仍可触发 Team 入口改写。
```

这里的 `fallback_count` 指“安全回退次数”，不是崩溃次数。它表示系统判断当前输入不应该被真实替换，于是保留 AutoGen 原生行为。

## 总体对比

```text
off_applied_count: 0
off_fallback_count: 1
on_applied_count: 2
on_fallback_count: 4
on_token_delta_task: 1519
on_fallback_reasons:
  - missing_team_task_argument
  - team_task_token_not_reduced
  - token_not_reduced
  - unsupported_team_task_type
```

中文解释：

- `applied_count`：真实替换成功次数。
- `fallback_count`：安全回退次数。
- `team_task_token_not_reduced`：直接替换后的 task 不比原 task 更省 token。
- `token_not_reduced`：按 receiver 的 SHP wire + Prompt View 广播口径也不划算。
- `unsupported_team_task_type`：当前 Team 层只支持 `task: str`，复杂任务类型保留原生行为。
- `missing_team_task_argument`：`task=None` 或没有任务参数。

## off 模式

配置：

```text
AGENTLITE_AUTOGEN_BROADCAST_MODE=real-rewrite
AGENTLITE_AUTOGEN_TEAM_REWRITE=0
```

结果：

```text
event_count: 1

fallback_count: 1
fallback_reasons:
  - team_level_real_rewrite_not_enabled_for_guarded_agent_input

```

AutoGen stream 侧：

```text
switch_off_long:
  rewrite: false
  native_marker_count: 18
```

说明：开关关闭时，即使是长 `task: str`，系统也只记录审计，不做真实替换。

## on 模式

配置：

```text
AGENTLITE_AUTOGEN_BROADCAST_MODE=real-rewrite
AGENTLITE_AUTOGEN_TEAM_REWRITE=1
```

结果：

```text
event_count: 6
applied_count: 2
fallback_count: 4
real_message_mutation_count: 2
native_task_tokens: 4616
rewritten_task_tokens: 3097
token_delta_native_task_minus_rewrite: 1519
token_delta_native_broadcast_minus_rewrite: 4311
```

case 结果：

| case | 预期 | 实际 |
|---|---|---|
| long_stream | 长字符串可改写 | rewrite=true, native_marker_count=0 |
| short_stream | 短任务不划算，回退 | rewrite=false, native_marker_count=1 |
| message_task | TextMessage task 暂不支持，回退 | rewrite=false, native_marker_count=18 |
| list_task | list task 暂不支持，回退 | rewrite=false, native_marker_count=18 |
| none_task | 缺少 task，回退 | rewrite=false, native_marker_count=0 |
| run_long_indirect | `run()` 间接路径可改写 | rewrite=true, native_marker_count=0 |

## 可以表述

```text
AgentLite 的 AutoGen Team 入口接管已经具备边界守卫：只有长字符串 task 在开关开启且成本门控通过时才真实替换；短任务、复杂 task 类型、缺 task、开关关闭等场景都会保留 AutoGen 原生行为并记录 fallback 审计。
```

## 仍不能表述

```text
已经支持所有 AutoGen task 类型的 Team 层替换；
已经接管 AutoGen Studio 网页端；
已经重写 AutoGen 所有内部私有消息队列；
已经覆盖所有 AutoGen Team 实现。
```

下一步建议：进入更贴近真实 AutoGen 应用的多轮 Team benchmark，用实际任务让 Team 层改写、agent 输入层改写、StatePool/Prompt View 共同工作，并比较原生 AutoGen 与 AgentLite 托管 AutoGen 的端到端 token、fallback、schema 和质量指标。
