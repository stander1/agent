# v5.14h 正式规模回归验收

## 1. 为什么需要这一阶段

v5.14f 已经证明 AgentLite 在完整 A1-A10/B1-B10 单次正式实验中明显降低了
Provider Token 与端到端协作 Token，但没有通过全部质量门禁：

- A10 接管组最终交付不完整且存在阻断问题；
- 记忆归因把“2 人”误识别为预算 `2`；
- 审查 Agent 已判定某个 active 结论违反硬约束，但该结论仍污染后续任务。

v5.14g 已用确定性 openEuler 验收证明通用修复本身成立。v5.14h 的任务是把
这些修复放回真实 Provider、完整十轮连续任务链，确认成本优势没有以质量下降为
代价，且审查冲突治理在真实 Trace 中可审计。

## 2. 公平性冻结

v5.14h 不创建新题目，也不调整 Agent 提示词。运行入口直接读取 v5.14f 的：

```text
question_A_formal.json
question_B_formal.json
agent_config.json
agent_config_B.json
```

预注册固定：

- Provider：MiMo `mimo-v2.5`；
- `temperature=0`；
- `max_turns=9`；
- Native、Observed、Managed 三组；
- Provider Token 降低至少 15%；
- 端到端协作 Token 降低至少 15%；
- 总体匿名质量非劣界限 0.3；
- A10/B10 最低分 7，且相对 Native 非劣界限 1；
- 错误记忆命中、当前任务保真失败、协议泄漏、路由状态误入池均为 0。

验收器会逐项比较 v5.14f 与 v5.14h 的旧阈值，并核对 A/B 冻结文件 SHA-256。
任何漂移都会直接导致验收失败。

## 3. 新增治理证据

生产运行时仍按动态能力画像和语义动作识别审查权限，不依赖
Planner、Writer、Reviewer 固定名称。每个权威审查结果记录：

```text
semantic_action
capabilities
blocking
targeted_memory_ids
deprecated_memory_ids
blocker_admission_status
blocker_memory_refs
```

报告新增以下指标：

```text
review_governance_event_count
review_governance_blocking_count
review_governance_positive_count
review_governance_targeted_memory_count
review_governance_deprecated_memory_count
review_governance_blocker_admitted_count
review_governance_targeted_without_deprecation_count
review_governance_unexpected_deprecation_count
review_governance_blocking_without_admitted_blocker_count
review_governance_nonblocking_side_effect_count
review_governance_failure_event_count
```

## 4. 门禁语义

每个 A/B 场景至少要出现一次动态审查权限事件，证明真实 Team 中的能力画像链路
被执行。阻断事件数量不设最小值，因为 Provider 如果直接生成合格结果，本轮不需要
拒绝任何 active 结论。

一旦出现阻断：

1. 只有被阻断文本明确定位的 active 记忆可以软废弃；
2. 所有被定位的 active 记忆都必须完成软废弃；
3. 阻断结论必须经过候选池、规则准入和 MemoryView 链路；
4. 非阻断审查不得产生软废弃或阻断准入副作用；
5. 任一不完整或越界动作都计为治理失败并使正式验收失败。

## 5. 成本边界

治理 Trace 和本地规则检查属于本地运行时开销，不调用控制 LLM。
正式结果仍同时报告：

```text
Provider 实际 Token
直接消息 Token
Prompt View Token
记忆读取 Token
控制 LLM Token
重试 Token
端到端协作 Token
双重匿名质量分
最终交付完整性
```

因此不能只依据消息缩短宣称节省，也不能用更短但质量更差的输出形成成本优势。

## 6. 解释边界

本阶段是一轮完整正式规模回归，可以验证此次修复是否在同一冻结任务上恢复质量，
但仍不能估计跨多次独立重复运行的方差和置信区间。若 v5.14h 全部门禁通过，后续
再进行多重复统计实验，而不是继续修改同一轮数据的阈值。
