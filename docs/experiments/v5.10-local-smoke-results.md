# v5.10 实验口径校准与本地 Smoke 记录

生成日期：2026-06-23

## 1. 本轮目标

v5.10 不引入新的低开销协同机制，主要校准实验口径：

1. 将旧 `baseline_text` 保留为压力测试口径，并新增正式主对照 `baseline_bounded_nl_framework`。
2. `baseline_bounded_nl_framework` 只使用自然语言 bounded context，不使用 SHP、state_ref、memory_ref、PromptView 或 MemoryView。
3. A/B 任务组按 `group_id` 拆分独立 conversation thread，主 baseline 不再跨 A/B 滚动全文历史。
4. 最终交付物拆分为 `draft_answer`、`review_report`、`final_answer`，质量裁判只比较 `final_answer`。
5. 摘要更新成本记录为 `summary_update_*`，避免 bounded baseline 的上下文压缩成本被忽略。

## 2. 已实现内容

### 2.1 模式命名

新增模式：

```text
baseline_stress_full_broadcast
baseline_bounded_nl_framework
```

保留旧模式：

```text
baseline_text
runtime_stub
runtime_lite
```

其中 `baseline_text` 作为兼容别名继续表示全文广播压力测试。

### 2.2 Bounded Baseline

`baseline_bounded_nl_framework` 的跨任务传递内容限制为：

```text
accepted_final_output
bounded_summary
recent_key_messages_k
```

固定参数：

```text
local_round_context_budget = 8000 tokens
cross_round_context_budget = 1200 tokens
recent_key_messages_k = 2
summary_max_tokens = 500
```

当前摘要实现为 deterministic summary，并记录：

```text
summary_update_count
summary_update_estimated_tokens
summary_update_method = deterministic
```

后续如果替换为 LLM summary，需要把 Provider usage 写入：

```text
summary_update_prompt_tokens
summary_update_completion_tokens
summary_update_total_tokens
```

### 2.3 最终交付物口径

`deliverables.json/jsonl` 将保留：

```text
draft_answer
review_report
final_answer
deliverable_role
```

其中：

```text
WriterAgent -> draft_answer / final_answer
ReviewerAgent -> review_report
```

A10/B10 质量裁判应只读取 `final_answer.content`。

输出目录：

```text

```

报告文件：


核心结果：

|---|---:|---:|
| task_runs | 2 | 2 |

| llm_total_tokens | 0 | 0 |
| end_to_end_collaboration_tokens | 21683 | 9510 |
| prompt_view_tokens | 6678 | 4763 |
| retrieved_memory_tokens | 0 | 407 |

解释：

- 本地 smoke 中没有 LLM 调用，因此 `llm_total_tokens=0` 是正常结果。
- `baseline_bounded_nl_framework` 已产生 deterministic summary 成本，说明 bounded baseline 没有免费使用摘要压缩。
- `runtime_lite` 仍然走状态池、记忆池、读租约与 MemoryView 路径。
