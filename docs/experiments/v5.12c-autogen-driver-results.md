# v5.12c AutoGen Driver 验证结果

## 验证目标

验证 `agentlite run --framework autogen -- python app.py` 能够在用户脚本执行前加载 AutoGen Driver，并在用户脚本正常导入 AutoGen 风格模块时自动安装消息生命周期 wrapper。

本轮不安装真实 AutoGen 包，先使用测试中的伪 `autogen_agentchat` 包验证透明接入边界。真实 AutoGen 最小样例放入 `v5.12d`。

## 已验证内容

```text
未安装 AutoGen 包时：
  driver=autogen
  status=active
  hooks_active=true
  framework_available=false 或取决于当前 Python 环境
  import hook 保持等待状态

伪 autogen_agentchat.agents.AssistantAgent：
  用户脚本正常 from autogen_agentchat.agents import AssistantAgent
  用户脚本正常 await agent.on_messages(...)
  AutoGen 风格返回值保持不变
  AGENTLITE_AUTOGEN_DRIVER_ACTIVE=1
  bootstrap_status.json: hooks_active=true
  autogen_driver/trace.jsonl 记录 autogen_agent_receive
  autogen_driver/trace.jsonl 记录 autogen_agent_output
  trace 中出现 artifact_state
```
