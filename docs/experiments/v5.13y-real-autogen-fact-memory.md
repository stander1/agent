# v5.13y 真实 AutoGen 事实级公平对照

## 阶段定位

v5.13x 证明了事实级 Claim、CCF、Batch Compaction 和 MemoryView 的确定性行为，
但没有证明真实模型条件下的端到端收益。v5.13y 不继续扩展业务规则，只补真实
AutoGen 三组对照和证据闭环。

## 实验变量

唯一实验变量是 AgentLite 的工作模式：

- Native：原生 AutoGen；
- Observed：AgentLite 钩子启用，但不改写消息；
- Managed：AgentLite 接管消息改写、状态引用和 TLC-Memory。

任务、Team、Provider、模型参数、调用上限和重试参数保持一致。Observed 用于
分离“仅安装观测钩子”的开销，不能与 Managed 混为一组。

## 指标解释

Provider Token 回答“真实模型账单是多少”；归一化公共调用回答“相同逻辑调用的
Prompt 是否变短”；端到端协作 Token 回答“显式消息节省是否被记忆读取、控制或
重试转移”。三者同时报告，不用单一百分比替代。

质量门禁要求 Managed 的匿名综合均分不比 Native 低超过 0.5 分，且完整交付数量
不能少于 Native。技术评审发现会对主评审得分设上限。

## 事实级抽查边界

自动报告给出 Claim、Slot、冲突和 active value 的数量，并导出采用证据样本。
人工复核需要把样本与对应任务输出逐条比对；在人工标签完成前，只能报告自动分类
分布，不能宣称假阳性率或假阴性率已经得到人工验证。
