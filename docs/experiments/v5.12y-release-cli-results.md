# v5.12y Release CLI Results

`v5.12y` 不改变 v5.12x 已验证的 AutoGen Driver 底层改写能力，重点补齐发行版入口：

- `agentlite run --framework autogen --rewrite all -- python app.py`
- `agentlite doctor --framework autogen`
- `agentlite version`
- `examples/run_release_gate.py`

## CLI Presets

`--rewrite` 预设把原本需要用户手动设置的环境变量收进命令行：

| 预设 | 行为 |
|---|---|
| `off` | 仅观察与影子审计，不真实改写 |
| `agent` | 开启简单 agent 文本输入改写 |
| `team` | 开启 AutoGen Team 入口长 task 改写 |
| `non-text` | 开启安全 Handoff / ToolSummary content 改写 |
| `all` | 启用当前 v5.12 支持的全部真实改写门控 |
