# v5.13c AutoGen Core Receiver Hydration Results

## 结论

`v5.13c` 在 v5.13b 的类型保持真实改写基础上，新增 receiver 侧 Prompt View hydration。

中文解释：

```text
发送端：AutoGen Core message.content 长正文被替换成 AgentLite SHP state_ref wire；
传输中：Runtime 队列里携带的是低开销 wire 内容；
接收端：BaseAgent.on_message 进入用户 handler 前，把 wire 自动转成 Prompt View；
用户 handler：仍收到原 Python 消息类型，不需要自己解析 shp_wire。
```

这一步更接近“无痛接管”：接收方不再直接看到 AgentLite wire marker。

## 当前能力边界

可以表述为：

```text
AgentLite 已经能在 AutoGen Core Runtime 的 send_message / publish_message 入口，
对含有 content / body / text 文本字段的消息做类型保持真实改写，
并在 BaseAgent.on_message 接收端自动转换为 Prompt View。
```

仍不能表述为：

```text
已经接管 AutoGen Studio / 网页端后端进程；
已经覆盖分布式 runtime、远程 runtime、跨进程 transport；
已经对所有任意 Python 对象保证语义等价；
已经证明真实 LLM agent 在 Prompt View 下质量不下降。
```

下一步建议：

```text
1. 做 AutoGen Core message 结构矩阵：dataclass / dict / pydantic / namedtuple / mutable object；
2. 验证 AutoGen Studio 或网页端后端是否可通过 agentlite 启动注入；
3. 做真实 AssistantAgent / GroupChat + Core 混合链路的端到端实验。
```
