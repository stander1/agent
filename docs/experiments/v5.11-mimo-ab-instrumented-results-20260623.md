## What This Proves

1. The low-overhead communication layer is still effective on token cost:
   - provider token cost down 46.15%;
   - end-to-end collaboration token cost down 79.19%.

2. The latency issue is not caused by StatePool / MemoryStore:
   - local runtime measured overhead is about 2.55s;
   - runtime_lite LLM wall time is about 2,019.19s;
   - local overhead is only about 0.13% of LLM time.

3. The next bottleneck is LLM call policy and completion generation:
   - Writer has the largest single runtime_lite LLM wall time;
   - Reviewer is also high;
   - Planner and MemoryManager are not negligible;
   - MemoryManager deserves special review because memory admission itself is already rule-first.
