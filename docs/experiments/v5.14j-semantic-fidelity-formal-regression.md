# v5.14j 语义保真正式回归说明

## 目的

v5.14h 已证明通信 Token 显著下降，但 Managed 组出现 A2、A4、A10 和 B10
质量失败。v5.14i 对根因进行了通用机制修复，本阶段验证这些修复在真实
Provider 完整任务链中是否恢复交付质量，同时保留低开销优势。

## 不变量

本阶段不修改：

- A1-A10、B1-B10 冻结输入；
- A/B Agent 提示词与角色；
- `mimo-v2.5`、温度 0、最多 9 轮；
- Native、Observed、Managed 三组实验结构；
- 双重匿名质量评估；
- v5.14h 继承的成本、质量、交付、记忆和治理阈值。

任务和 Agent 文件均由 SHA-256 绑定，实验开始后复制到
`system/frozen-inputs`，续跑时再次校验。

## 新增证据

- 协议卫生按模型输入、Agent 输出、团队最终输出三个表面分别统计；
- 错误记忆命中按 A/B 场景分别检查，避免总量抵消；
- 记忆采用守卫的结果类型保持失败数必须为 0；
- A2/A4/A10/B10 使用同一通用交付与盲评规则逐项复核；
- v5.14h 指标只作为诊断参考，不参与本次通过判定。

## 结果解释

只有旧门槛与新增门槛全部通过，才能说明 v5.14i 修复在冻结正式口径下
恢复了质量。单次运行通过仍不能替代重复实验，后续需要固定版本后进行
多次独立重复，以报告均值、方差和置信区间。
