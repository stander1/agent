# v5.14r 候选充分证据正式回归

## 目标

在不改变 v5.14p 冻结实验条件和正式门禁的前提下，验证 v5.14q 是否修复：

1. 验证类接收者因压缩而看不到完整当前候选交付物；
2. 连续任务输出把当前任务错误推进为后续编号。

## 新增证据

- 当前候选必需、可用、完整改写和缺失次数；
- 当前候选来源 Token 与实际选中 Token；
- 当前任务身份锚点次数；
- 当前任务身份漂移拦截次数。

这些指标只用于证明机制执行，不替代 Provider 总 Token、端到端协作成本、
双盲质量、完整交付、记忆正确性和协议卫生门禁。

## 公平性

- Native、Observed、Managed 使用同一任务、Agent、模型、温度和轮次；
- 不为 A/B 题、旅游、安全领域或固定角色名称编写运行时规则；
- 验证类接收者的识别来自动态能力画像和语义动作；
- 当前候选是本轮临时证据，不直接晋升为长期记忆。
