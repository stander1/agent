# v5.12t AutoGen ToolCallSummary Rewrite Matrix 实验记录

## 版本定位

`v5.12t` 是 ToolCallSummaryMessage typed rewrite candidate 后的矩阵压测版本。

rewrite matrix：改写矩阵。这里不是做真实改写，而是把应该安全、应该不安全、应该因成本不合算而回退的 ToolCallSummary 场景放在同一组测试里，证明系统不会把工具调用链路压坏。

## 新增内容

- AutoGen Driver phase 更新为 `v5.12t`。
- 新增 `examples/autogen_tool_summary_matrix_smoke.py`。
- 新增 `examples/run_autogen_tool_summary_matrix_smoke.py`。
- 矩阵覆盖五类场景：
  - `aligned_single`：单工具调用，`tool_calls.id == results.call_id`；
  - `mismatched_call_id`：工具结果 `call_id` 与工具请求不匹配；
  - `multi_tool_complete`：多工具调用与多工具结果完整对齐；
  - `short_cost_gate`：短 ToolCallSummary，候选 token 不降低；
  - `error_result_preserved`：`is_error=true` 的工具结果必须保留错误状态。

## 可表述结论

AgentLite 已经通过矩阵证明：AutoGen `ToolCallSummaryMessage` 的类型化改写候选能够区分安全与不安全工具链路；`call_id` 不匹配会被拦截，短内容不降成本会被成本门拦截，错误结果的 `is_error=true` 能被保留。

## 下一步建议

下一步可以进入 `v5.12u ToolCallSummary rewrite switch` 设计，但建议仍然默认关闭。只有当矩阵条件全部满足、`token_reduced=true`、`tool_result_lineage_complete=true` 且显式开关开启时，才允许真实替换 `ToolCallSummaryMessage.content`。
