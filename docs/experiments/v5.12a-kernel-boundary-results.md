# v5.12a Framework-Neutral Kernel 验证结果

## 验证目标

验证三线治理能力已经可以脱离当前 `V0Runtime` 调度循环，被框架 Adapter 独立调用。

## 实现结果

新增：

```text
agent_runtime/core/kernel.py
agent_runtime/adapters/base.py
tests/test_collaboration_kernel.py
```

`CollaborationKernel` 当前负责：

```text
Kernel session；
MemoryContext；
before_agent_receive；
validate / after_agent_output；
StatePool 写入；
SHP handoff；
communication gate；
消息成本记录。
```

`V0Runtime` 当前保留：

```text
自研 Agent 调度循环；
baseline 历史；
Final Schema 修复时序；
异步 Memory Admission 调度；
最终交付选择。
```

## 测试口径

Kernel 独立测试没有使用 `DeterministicAgent` 执行调度，而是通过 Fake Adapter 和 `AgentDescriptor` 直接调用：

```text
open_session
→ after_agent_output
→ failure_state
→ before_agent_receive
→ role-aware Prompt View
→ build_handoff
→ reviewer route
```

同时验证：

- `FrameworkAdapter` Protocol 可运行时检查；
- Kernel session 打开与关闭事件进入 trace；
- `V0Runtime` 和 Kernel 共用 StatePool、MemoryStore、CommunicationGate；
- 现有运行时核心测试无行为回归。
