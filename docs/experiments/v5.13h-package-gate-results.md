# v5.13h Package Gate Results

## 目标

v5.13h 验证 AgentLite 不只是在源码目录内 smoke test 能运行，而是能构建为 wheel 包、安装到隔离目录，并从源码目录外通过统一 CLI 接管 AutoGen Team/Core 混合链路。

这一步对应“正式命令行接管”的工程门槛：用户安装包后可以使用 `agentlite autogen -- python app.py`，或等价的 `agentlite run --framework autogen --rewrite all -- python app.py`。AutoGen 脚本本身不需要显式替换 Agent 类，也不需要手工注入 Runtime。


## Team 改写证据

安装包环境下运行：

```text
python -m agent_runtime.cli run --framework autogen --rewrite all -- python examples\autogen_team_benchmark_app.py
```

结果：

```text
installed_agentlite_cli_rewrite: passed
agentlite_active: true
contains_team_rewrite_marker: true
contains_state_pool_marker: true
contains_broadcast_manifest: true
contains_receiver_prompt_views: true
native_marker_count: 0
```

含义：

```text
AutoGen Team 入口长 task 已经被替换为 AgentLite SHP state-ref 包；
完整原文没有继续以 native full broadcast 形式传给下游 Agent；
接收侧拿到的是包含 Prompt View 的可用输入。
```

## 结论

v5.13h 可以表述为：

```text
AgentLite 已经具备安装包级别的 AutoGen 单进程接管能力。用户通过 CLI 启动普通 AutoGen Python 脚本时，Team 入口消息、AgentChat Agent 输入、Core request、Core response 可以被 AgentLite 改写为状态引用和 Prompt View，最终输出不会泄漏 AgentLite wire marker。
```

仍然不能表述为：

```text
已经自动接管 AutoGen Studio / 网页端后端进程；
已经覆盖分布式 runtime、远程 runtime、跨进程 transport；
已经完成真实 LLM agent 的质量不下降实验。
```
