# v5.12u AutoGen ToolCallSummary Rewrite Switch Results

## 结论

`v5.12u` 已经完成 `ToolCallSummaryMessage.content` 层的真实替换开关验证。

这里的 “rewrite switch” 指“改写开关”：默认关闭时，系统只生成类型化改写候选并记录审计事件，不改变 AutoGen 原生消息；显式打开 `AGENTLITE_AUTOGEN_TOOL_SUMMARY_REWRITE=1` 后，只有在工具调用链路、结果链路、schema、Prompt View 和成本门控全部通过时，才替换 `ToolCallSummaryMessage.content`。

本轮验证通过，且 AutoGen agent 实际收到的仍是原生 `ToolCallSummaryMessage` 对象，只是 `content` 字段被替换为 SHP wire + Prompt View。`tool_calls` 和 `results` 仍由 AutoGen 原生对象承载。

## 开关对比

| 模式 | rewrite_enabled | applied_count | fallback_count | mutation_applied_count | agent 看到候选标记 | agent 看到原生大文本标记 | token delta |
|---|---:|---:|---:|---:|---:|---:|---:|
| off | false | 0 | 1 | 0 | false | 18 | 1036 |
| on | true | 1 | 0 | 1 | true | 0 | 1044 |

术语说明：

- `applied_count`：真实替换成功次数。
- `fallback_count`：安全回退次数，也就是系统判断“不应该真的替换”后保留原生消息的次数。
- `mutation_applied_count`：候选层记录的“是否真的改动了原生消息内容”次数。
- `token delta`：原生输入 token 数减去替换后输入 token 数，数值越大表示本次输入侧节省越多。

## 安全条件

ToolCallSummary 真实改写需要全部满足：

```text
message_type_preserved: true
source_preserved: true
id_preserved: true
metadata_preserved: true
tool_calls_preserved: true
tool_results_preserved: true
tool_call_ids_preserved: true
tool_result_call_ids_preserved: true
tool_result_lineage_complete: true
content_replaced_only: true
state_ref_available: true
schema_valid: true
prompt_view_available: true
token_reduced: true
```

这些条件对应创新方案中的 Contract Guard、SHP-State、Prompt View 和 CSCC 成本门控。也就是说，系统不会只为了降低 token 而破坏 AutoGen 的工具调用语义。
