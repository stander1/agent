# v5.13d AutoGen Core Message Matrix Results

## 结论

`v5.13d` 扩展了 AutoGen Core 无痛接管的消息结构覆盖面。

本轮验证的不再只是单一 dataclass `content` 字段，而是：

```text
dataclass + content
dataclass + body
dataclass + text
pydantic BaseModel + content
publish_message 广播路径 + content
```

每条消息都完成：

```text
发送端类型保持真实改写；
StatePool 写入；
SHP state_ref wire 传输；
接收端 BaseAgent.on_message 自动 Prompt View hydration；
用户 handler 仍收到原 Python 消息类型；
AgentLite wire marker 不泄漏给用户 handler。
```

## 边界说明

真实 AutoGen Core handler 不支持裸 `dict` 作为 message handler 类型，因为本地 AutoGen Core 注册时会报：

```text
ValueError: No serializers found for type <class 'dict'>.
```

因此 v5.13d 的真实 AutoGen smoke 不把 dict 作为 handler 消息类型；但底层 helper 已通过单测覆盖 dict、namedtuple、pydantic、dataclass、普通可变对象的字段识别与同类型克隆。
