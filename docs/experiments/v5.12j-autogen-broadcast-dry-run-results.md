# v5.12j AutoGen 广播 dry-run 改写与安全回退实验记录

## 版本定位

`v5.12j` 仍属于 AutoGen 透明托管接入链路，不真实替换 AutoGen Team 的广播策略。该版本在 `v5.12i` 的 per-receiver 广播影子计划上增加三类安全能力：

```text
1. broadcast mode 功能开关；
2. dry-run rewrite 候选改写 diff；
3. fallback 回退审计。
```

这里的 `dry-run rewrite` 指“生成候选改写结果并记录差异，但不交给 AutoGen agent 使用”。因此本版本仍然保持 AutoGen 原生消息不变。

## 实现内容

- 新增环境变量 `AGENTLITE_AUTOGEN_BROADCAST_MODE`。
- 支持三种模式：
  - `shadow-only`：默认模式，只记录影子计划。
  - `dry-run-rewrite`：生成候选改写 diff，但保持原生 AutoGen 广播。
  - `real-rewrite`：当前只接受配置并自动回退，不真实改写消息。
- AutoGen Driver phase 更新为 `v5.12j`。
- `autogen_broadcast_replacement_shadow` 事件新增 `broadcast_mode` 和 `rewrite_dry_run` 字段。
- `rewrite_dry_run` 记录：
  - `candidate_generated`
  - `rewrite_safe`
  - `fallback_required`
  - `fallback_reasons`
  - `applied_action`
  - `real_message_mutation`
  - 原生广播 token 与候选改写 token 对比。
- 新增回退条件：
  - 接收方缺失；
  - `state_ref` 缺失；
  - SHP wire schema 不合法；
  - Prompt View 缺失；
  - token 未降低；
  - `real-rewrite` 在 v5.12j 中被请求。
- runner 默认以 `dry-run-rewrite` 运行 v5.12j smoke。

## 回退验证

单元测试中新增 `real-rewrite` 回退审计样例：

```text
mode: real-rewrite
fallback_required: true
fallback_reasons: real_rewrite_not_implemented_in_v5_12j
applied_action: fallback_keep_native_autogen_broadcast
real_message_mutation: false
```

这说明即使用户误开真实改写模式，v5.12j 也不会改 AutoGen 原生消息，而是记录回退原因并继续保持原生广播。

## 可表述结论

AgentLite 已经具备 AutoGen Team 广播替换前的安全演练能力：可以生成每个接收方的候选 SHP wire 包，记录 Prompt View 成本，判断是否满足替换条件，并在不满足条件或请求真实改写时回退到 AutoGen 原生广播。

在本次三 Agent smoke 中，原生全文广播估算口径为 `42858` tokens，dry-run 候选 `SHP wire + Prompt View` 为 `2350` tokens，下降约 `94.5%`；同时 `real_message_mutation_count=0`，证明实验没有改变 AutoGen 原生执行路径。

## 仍不能表述为

```text
已经真实替换 AutoGen Team 的广播策略；
已经改变 AutoGen agent 间的实际传输内容；
已经接管 AutoGen Studio / 网页端；
已经完成真实 LLM AutoGen 任务的质量、延迟、token 综合评估；
已经证明所有 AutoGen Team 类型都可以无修改替换。
```

## 下一步建议

`v5.12k` 可以在继续可回滚的前提下进入更窄范围的真实改写验证：

```text
1. 只针对最简单 TextMessage 广播做 real-rewrite 小样例；
2. 只在 receiver、state_ref、Prompt View、schema 全部安全时启用；
3. 保留自动 fallback 到 AutoGen 原生消息；
4. 对比 real-rewrite 与 dry-run-rewrite 的 trace 是否一致；
5. 若 termination_condition 或流式输出异常，立即回退。
```
