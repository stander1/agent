# v4.0 Full A/B Experiment Results

## Scope

This experiment runs both continuous task groups under v4.0:

- A: `benchmarks/travel_task_group_a.json`
- B: `benchmarks/security_task_group_b.json`
- Modes: `baseline_text` and `runtime_lite`
- Rounds: `1`
- Tasks per group: `10`
- LLM: MiMo v2.5
- Tokenizer: `tiktoken:cl100k_base 0.13.0`

Raw outputs:

```text

runs/v4.0-ab-security-b
```

## Combined Reading

| Group | E2E token reduction | LLM token reduction | Runtime latency change | Final schema coverage |
| --- | ---: | ---: | ---: | ---: |
| A | -89.3% | -77.9% | +94.6% | 14/16 |
| B | -86.8% | -75.9% | +114.1% | 10/12 |

v4.0 proves the core cost-control claim:

```text
runtime_lite reduces total collaboration token cost
without using full raw access as a hidden cost sink.
```

However, the current runtime is not yet v5 competition-ready:

- final deliverable schema coverage is still incomplete for both A and B;
- format retry/fallback rates are high;
- runtime latency roughly doubles because of extra LLM guard retries;
- the next step should focus on v5 delivery hardening:
  - reduce fallback count;
  - improve final schema completion;
  - introduce adapter boundary;
  - produce stable 10-task reproducibility scripts.
