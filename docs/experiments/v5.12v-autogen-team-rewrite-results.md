# v5.12v AutoGen Team Rewrite Results

## 结论

`v5.12v` 将 AutoGen 接管位置从 “agent 输入层” 前推到 `RoundRobinGroupChat.run_stream(task=...)` 的 Team 入口层。

这里的 Team rewrite 指：在 AutoGen Team 开始原生分发任务之前，AgentLite 先把长 `task` 正文写入 StatePool，再把传入 AutoGen Team 的任务内容替换为紧凑的 SHP broadcast manifest + receiver Prompt Views。

本版本仍然是受控开关，不默认改变 Team 行为：

```text
AGENTLITE_AUTOGEN_BROADCAST_MODE=real-rewrite
AGENTLITE_AUTOGEN_TEAM_REWRITE=1
```

中文解释：

- `applied_count`：Team 入口真实替换成功次数。
- `fallback_count`：安全回退次数，本次为 0。
- `real_message_mutation_count`：真实改动传入 AutoGen Team 的任务内容次数。
- `native_task_tokens`：原始 task 文本 token 数。
- `rewritten_task_tokens`：替换后的紧凑 task token 数。
- `native_full_broadcast_tokens`：如果原生全文按参与者广播，估算的总 token。
- `wire_plus_prompt_view_tokens`：SHP wire + Prompt View 的广播替代成本。

## 可以表述

```text
AgentLite 已经可以在 AutoGen Python 代码端通过托管启动接管 Team 入口层：当用户调用 RoundRobinGroupChat.run_stream(task=长文本) 时，AgentLite 可在 AutoGen 原生分发前将长任务迁移到 StatePool，并把传入 Team 的任务替换为紧凑的 SHP broadcast manifest + Prompt Views。
```

## 仍不能表述

```text
已经接管 AutoGen Studio 网页端；
已经重写 AutoGen 所有 Team 内部私有消息队列；
已经支持所有 task 类型的 Team 层替换；
已经覆盖所有 AutoGen Team 实现。
```

当前实现的安全边界：

```text
只对 task: str 的 Team 入口做真实替换；
BaseChatMessage 或消息列表类型 task 仍安全回退；
Team 开关默认关闭；
agent 输入层的 TextMessage/HandoffMessage/ToolCallSummaryMessage 替换仍继续作为下游保护。
```

下一步建议进入 Team rewrite matrix：覆盖 `task=None`、短 task、`BaseChatMessage task`、消息列表 task、缺参与者、开关关闭、`run` 间接调用 `run_stream` 等边界，证明 Team 入口接管不会误伤复杂任务。
