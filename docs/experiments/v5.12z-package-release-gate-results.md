## 本轮修复

本轮包级验证暴露并修复了两个发布前问题：

1. Windows 长路径问题：在中文长路径下，`state_cold/*.audit.json` 超过 260 字符时，普通 `Path.write_text()` 会报 `FileNotFoundError`。`StatePoolLite` 已增加长路径安全 I/O。
2. 验证脚本编码问题：中文路径在子进程 stdout 中可能被 Windows 控制台编码破坏，导致 import path 判断误报失败。`run_package_release_gate.py` 已设置 `PYTHONIOENCODING=utf-8`，并让安装路径 JSON 输出使用 ASCII escape。
