# v5.13g AutoGen Mixed Team/Core Results

## 结论

`v5.13g` 验证了 AgentLite 在同一个真实 AutoGen 用户脚本中同时接管 AgentChat Team 层和 AutoGen Core 层。

本轮链路：

```text
RoundRobinGroupChat.run_stream(task=长文本)
-> BaseChatAgent.on_messages()
-> SingleThreadedAgentRuntime.send_message(sender=...)
-> Core worker
-> Team final output
```

这说明当前接管机制不再只是分别验证 Team 或 Core，而是能在混合链路中协同工作。

## 新增修正

本轮发现 Team 入口改写后的 AgentLite 包会继续进入 AgentChat Agent 输入层。若不处理，AgentChat 输入层会对已经压缩过的 AgentLite 包再次改写，造成双层包裹。

`v5.13g` 新增保护：

```text
AgentChat 输入层遇到已包含 AgentLite rewrite marker 的消息时，跳过二次真实改写；
这样 Team 包会直接交给 Bridge Agent，而不是再被 AGENTLITE_REAL_REWRITE 包一层。
```
