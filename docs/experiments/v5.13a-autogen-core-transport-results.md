# v5.13a AutoGen Core Transport Coverage Results

## 结论

`v5.13a` 将 AutoGen 接管范围从 AgentChat / Team 入口继续下探到
`autogen_core.SingleThreadedAgentRuntime` 的底层通信入口：

- `send_message`
- `publish_message`

本版本不改变命令行形式，也不对任意 Core 消息做真实替换。原因是
AutoGen Core 的接收方通常按 Python 原生消息类型分发，如果直接把任意对象
替换成字符串或通用包，可能破坏业务 handler 的类型匹配。

因此，本版本的目标是先完成“底层通信过程可观测、可状态化、可生成 SHP
替换候选”的接管底座：

```text
Core native message
-> StatePool state_ref
-> compact SHP shadow wire
-> receiver Prompt View
-> trace cost / schema / route audit
```

## 新增能力

```text
driver phase: v5.13a
new trace event: autogen_core_transport_shadow
expanded trace event: autogen_transport_input_state
new smoke app: examples/autogen_core_transport_smoke.py
new runner: examples/run_autogen_core_transport_smoke.py
```

`autogen_transport_input_state` 之前只覆盖 Core runtime 中的
`tool_call` / `tool_result` 类消息。现在只要 Core runtime 传输内容具有语义
payload，就会写入 StatePool 并记录路由元数据。

新增路由字段包括：

```text
transport_kind: direct | publish
method: send_message | publish_message
message_native_type
route_raw
declared_receiver
sender
message_id
```

## 含义

这一步证明：AgentLite 已经不只是在 AutoGen AgentChat Team 入口观察长任务，
也能在 AutoGen Core runtime 的底层 direct / publish 通信入口捕获真实业务
payload，并为后续真实改写生成稳定的 StatePool + SHP 证据链。

## 当前边界


```text

SingleThreadedAgentRuntime 的 send_message / publish_message 底层通信入口，
```
