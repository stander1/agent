# v5.13e AutoGen Core Request-Response Rewrite Results

## 结论

`v5.13e` 新增验证了 AutoGen Core `send_message()` 的返回路径。

之前已经覆盖：

```text
调用方 -> Runtime.send_message / publish_message -> 接收方 BaseAgent.on_message
```

本轮新增覆盖：

```text
接收方 handler 返回值 -> Runtime.send_message 返回值 -> 调用方
```

这说明 Core 的一次 RPC 风格协作不再只接管请求消息，也接管返回消息。

## 机制说明

返回路径的处理方式：

```text
1. Runtime.send_message 运行期间，driver 记录当前处于 Core 请求-响应链路；
2. BaseAgent.on_message 的用户 handler 返回长文本对象；
3. driver 将返回对象的 content/body/text 字段写入 StatePool；
4. handler 对 Runtime 返回同类型 SHP state_ref wire 对象；
5. Runtime.send_message 返回给调用方前，将 wire 自动水化为 Prompt View；
6. 调用方仍拿到原 Python 返回类型，且看不到 AgentLite wire marker。
```
