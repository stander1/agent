# v5.14x Evidence Fidelity Formal Regression

v5.14x verifies v5.14w under the unchanged real MiMo Provider A/B formal
experiment. It reuses the exact frozen A1-A10/B1-B10 tasks, capability-based
Agent configurations, model, temperature, nine-turn limit, anonymous judges,
and all v5.14v cost, quality, delivery, memory, review-governance, structured
state, and protocol-hygiene thresholds.

The new audit does not require a guard event. If the preflight causes the model
to follow the user's fallback directly, zero events is correct. Any observed
event must:

- preserve `blocked_and_deferred` status;
- identify at least one unavailable artifact;
- record the fallback explicitly supplied by the user;
- identify either a false read claim or a conflicting strong decision.

This stage does not modify the task, prompts, output length, Agent roles,
scoring thresholds, or baseline calculation. It is a single formal run and
does not estimate variance.
