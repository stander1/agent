# v5.12b Launcher 验证结果

## 验证目标

验证用户脚本不导入 AgentLite 时，Launcher 仍能在脚本执行前加载 Framework Driver，并对失败情况执行阻断。

## Probe Driver 托管实验

目标脚本只读取环境变量，没有导入 AgentLite。

执行链：

```text
Launcher
→ sitecustomize
→ probe Driver
→ 用户脚本
```

观察结果：

```text
target_probe=1
target_session=launch_<uuid>
Bootstrap status: active
Driver hooks: active
```

说明 Driver 已在用户代码之前激活。

## AutoGen Driver 占位实验

结果：

```text
Bootstrap status: awaiting_v5.12c_adapter
Driver hooks: inactive
```

如果目标环境没有 AutoGen，还会输出：

```text
No supported AutoGen package was detected in the target Python environment.
```

该结果符合版本边界：v5.12b 已加载 Driver，但没有伪装成已经接管 AutoGen。
