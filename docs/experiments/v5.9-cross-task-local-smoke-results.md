This smoke run proves that:

1. A and B can run in one shared runtime rather than isolated suite runs.
2. The cross-task report is generated automatically.
3. The runtime path records useful memory hits in the downstream suite.
4. The reduced collaboration cost is not caused by raw cold reads, because `raw_access_count=0`.
