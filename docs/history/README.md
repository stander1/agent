# Historical Documentation

This directory preserves documentation snapshots that previously served as
top-level repository entry points.

The files are retained to keep the development record complete. They may
describe intermediate capabilities, measurements, or limitations that were
later superseded. Current competition claims are defined by:

- `README.md`;
- `docs/competition/RESULTS_SNAPSHOT.md`;
- `docs/competition/v0.5.15-delivery-guide.md`;
- `docs/release/v0.5.15-final-release-notes.md`.

Historical snapshots are not packaged into the wheel, sdist, or curated
competition source bundle.
