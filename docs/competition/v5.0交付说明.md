# v5.0 交付说明

## 本版本新增内容

v5.0 的目标是把已有 runtime_lite 机制整理成比赛可复现交付形态，而不是新增重型协同机制。

新增文件：

- `agent_runtime/eval/competition_report.py`
- `examples/run_competition_eval.py`
- `tests/test_competition_report.py`
- `docs/competition/比赛报告骨架.md`

## 一键评测

完整运行 A/B：

```powershell
F:\software\anaconda\envs\multi-agent-demo\python.exe examples\run_competition_eval.py --provider mimo --suite A --suite B --config configs\llm.mimo.example.json --max-retries 4 --retry-backoff-seconds 3
```

复用已有运行结果生成报告：

```powershell
F:\software\anaconda\envs\multi-agent-demo\python.exe examples\run_competition_eval.py --provider mimo --skip-run --suite A --suite B --existing-run A=runs\v4.2-mimo-full-a --existing-run B=runs\v4.2-mimo-full-b --output-root runs\v5.0-mimo-full-report
```

## 输出

- `competition_report.json`：结构化报告，适合后续可视化或自动汇总。
- `competition_report.md`：Markdown 报告，可直接放入实验记录或答辩材料。

## 固定指标

本版本将以下指标固定为比赛汇报主口径：

- `llm_total_tokens`：provider usage 总 token。
- `end_to_end_collaboration_tokens`：系统内部端到端协作 token。
- `latency_ms`：端到端任务耗时。
- `fallback_count`：降级兜底次数。
- `provider_response_retry_count`：Provider 响应异常重试次数。
- `contract_retry_count`：协议格式重试次数。
- `deliverable_schema_hit_count / deliverable_schema_required_count`：最终交付字段完整度。
- `wrong_memory_hit_count`：错误记忆命中次数。
- `raw_access_count`：是否通过读取原文转移成本。
