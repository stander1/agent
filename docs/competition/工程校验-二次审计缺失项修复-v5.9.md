## 修复口径

本轮不处理 AutoGen 接入和 openEuler 部署。原因是用户已明确要求先把运行时内核做完整，再接主流 Agent 框架。

本轮采用比赛版 Lite 实现：每个审计缺口必须有明确代码接口、规则路径和测试证据；不把未来研究增强版说成已经完整实现。

## 仍需实测的数据项

R-04 的“跨任务端到端收益验证”需要真实 LLM API key。运行命令如下：

```powershell
$env:MIMO_API_KEY="..."
F:\software\anaconda\envs\multi-agent-demo\python.exe -u examples\run_cross_task_eval.py --provider mimo --suite A --suite B --config configs\llm.mimo.example.json --max-retries 4 --retry-backoff-seconds 3 --output-dir runs\v5.9-cross-task-mimo
```

该实验应观察：

1. `runtime_lite` 在 A->B 连续共享 runtime 时的 `llm_total_tokens`。
2. `retrieved_memory_tokens` 是否低于完整历史传递成本。
3. `memory_hit_count/useful_memory_hit_count` 是否说明跨任务复用真实发生。
4. `raw_access_count` 是否仍为低值，避免把通信成本转移到冷数据读取。
