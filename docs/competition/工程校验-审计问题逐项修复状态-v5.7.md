## 4. 仍需谨慎表述的边界

### 4.1 Lite 不是完整研究版

以下能力已经有工程入口，但仍是 Lite：

1. Schema Registry：没有 embedding similarity matching。
2. Conflict Resolver：规则版，没有人工/LLM 仲裁。
3. State GC：不是最终方案完整 9 层 GC。
4. Cold Access：已有 raw view cache，但没有 raw span resolver、prefetch scheduler。
5. Access Escalation：不是完整期望成本模型。
6. Read Lease：不是多进程/分布式租约。
7. Capability Router：只影响 SHP 路由决策，未改造主循环动态跳过 Agent。

### 4.2 按用户要求暂缓的内容

1. AutoGen adapter。
2. LangGraph / CrewAI / CAMEL adapter。
3. openEuler VM 部署验证。
4. openGauss 持久化后端。

这些不应在报告里写成已经完成，只能写成后续适配方向。
