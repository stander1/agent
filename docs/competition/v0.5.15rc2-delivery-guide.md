# AgentLite v0.5.15rc2 比赛交付说明

## 交付定位

AgentLite 是面向多智能体协作的跨框架运行时工具层。当前比赛候选版覆盖：

- StatePool 与结构化非文本状态传递；
- Prompt View、事实级 MemoryView、候选准入和冲突消解；
- AutoGen Team、Agent、Core 与最终交付接管；
- 通用语义桥、精确来源跨度、受控语义消歧和失败关闭；
- 通信、检索、控制模型、重试和 Provider Token 分账；
- 本地监控、CLI、不可变实验归档和 openEuler 验收。

固定 A/B 场景只作为冻结回归证据，不等同于跨领域普遍性证明。通用性
证据还包括提交后生成、实现期间不可见的 holdout 领域及语义变形门禁。

## 安装

从 wheel 安装：

```bash
python -m pip install multi_agent_collaboration_runtime-0.5.15rc2-py3-none-any.whl
agentlite version
agentlite doctor --framework autogen --json
```

从源码包安装：

```bash
python -m pip install multi_agent_collaboration_runtime-0.5.15rc2.tar.gz
agentlite version
```

开发检出仅用于开发与复现实验：

```bash
python -m pip install -e ".[autogen]"
```

## 最终兼容性验收

在干净的 openEuler 检出中运行：

```bash
bash experiments/v5.15y-installed-sdist-delivery-readiness/run_openeuler.sh
```

该门禁检查：

1. 发布契约定向回归；
2. wheel 独立安装及真实 AutoGen Team/Core smoke；
3. 完整源码 release gate 和全量单元测试；
4. wheel/sdist 成员、元数据和禁止目录；
5. sdist 隔离安装、导入来源、版本身份和 CLI；
6. 制品及证据归档 SHA256。

以 `acceptance_report.json` 中全部检查通过、公开发布阻塞项为空且
`open_source_publication_ready=true` 为最终发行兼容性成立条件。不要仅凭
脚本退出信息或目录存在推断通过。

## 凭据与证据

- Provider API Key 不得写入命令行、日志、仓库或实验归档。
- 不需要 Provider 的发布兼容性门禁不得读取 Provider 凭据。
- 正式实验按实验名和编号隔离，归档后校验 SHA256，再取回本地。
- 运行中的正式证据不得覆盖、删除或擅自重启。

## 已验证与未声明

技术门禁验证的是归档中记录的 Python、openEuler、AutoGen 和任务边界。
它不声明支持所有 AutoGen 私有 API、所有多智能体框架或所有自然语言
领域。成本和质量结论只适用于归档中的模型、提示、阈值和场景。
