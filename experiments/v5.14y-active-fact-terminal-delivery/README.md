the failed v5.14x formal run:

- component allocations, reserves, headings, and ambiguous numeric notes do
  not become active global budget caps;
- historical decision-log facts remain in the artifact but are excluded from
  the active claim view;
- selected entity values do not absorb trailing rationale headings;
- historical numeric values do not invalidate a current compliant artifact;
- a long review may reject older drafts and still approve the latest artifact,
  while revision language after the approval remains blocking;
- unavailable required evidence produces a complete explicit degraded
  deliverable instead of a deferred instruction packet.

The runtime changes do not recognize Question A/B, fixed business entities, or
fixed agent names. The acceptance uses generic fixtures and runs without an LLM
API key.
