# v5.14w Evidence Fidelity Governance

This mechanism acceptance verifies two domain-neutral runtime corrections
derived from the v5.14v formal evidence:

- budget estimates, upper bounds, allocation components, grouped thousands,
  and revision targets keep distinct semantic identities;
- when a task names a required artifact, the artifact is unavailable, and the
  user explicitly defines an evidence-insufficient fallback, AgentLite prevents
  an unsupported strong decision and preserves the fallback.

The guard remains inactive when the artifact content is supplied or exists
inside the target workspace. It does not infer domain policy, invent a fallback,
or identify Question A/B, fixed entities, or fixed agent roles.
